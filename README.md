# WXEntry · 微信增强模块

一个面向 **微信 8.0.80（3220）、构建 5032** 的 LSPosed 模块。安装包只是「引导器」，激活后从服务器下发加密内核，功能全部在内存中运行。

> 仅支持微信 8.0.80（3220）且安装包构建为 `0x28005032`（5032）；同版本的其它构建或其它版本，内核自检后直接停用（会弹一条提示说明原因）。

## 功能

- **防撤回**：对方撤回的消息本地保留原文，并补一条系统提示；撤回的图片也能点开看原图
- **朋友圈防删**：朋友删掉的动态继续保留，正文前标注「（这条朋友圈被删除啦）」
- **真名**：群里显示成员昵称
- **原图**：发图默认勾选原图
- **新群免打扰**：新加入的群聊自动免打扰
- **红包助手**：按群白名单自动抢
- **一键已读 / 批量清会话**：按公众号、群聊、个人分类清理

## 安装

1. 手机需已 Root 并装好 LSPosed；
2. 安装本仓库 Releases 里的 APK；
3. LSPosed 中勾选本模块，作用域选「微信」；
4. 强制停止微信后重新打开，长按首页右上角「+」激活。

## 更新

内核由服务器下发，菜单里「检查内核更新」或顶部版本行即可升级，不需要重装 APK。
