# WXEntry · 微信增强模块

一个面向 **微信 8.0.80（versionCode 3220）** 的 LSPosed 模块。安装包只包含加载器，功能代码在运行时以内存方式加载，不在本地保留明文。

> 仅支持微信 8.0.80（3220）；8.0.79 及更早版本会在自检后停用并提示原因，不影响微信本身的正常运行。

## 功能

### 聊天

- **防撤回**：对方撤回的消息在本地保留原文，并补一条系统提示；撤回的图片也能点开查看。
- **一键已读**：一次性清除所有会话的未读。
- **清空聊天列表**：按「公众号 / 群聊 / 个人」分类批量清理会话，可选择是否同时清空聊天记录。
- **新群免打扰**：新加入的群聊自动设为消息免打扰。
- **公众号取关**：批量取消关注，并把会话收回订阅号分组。

### 朋友圈

- **朋友圈防删**：朋友删除的动态在本地继续保留，正文前标注「（这条朋友圈被删除啦）」，图片与评论仍在。仅对他人动态生效，广告类不处理。

### 其它

- **真名**：群聊中显示成员备注名，按需查询、低功耗调度。
- **原图**：发图时默认勾选「原图」。
- **红包助手**：自动领取红包，支持按群白名单与延迟设置。
- **内核更新 / 重启微信**：菜单内直接检查更新、一键重启微信进程。

## 使用

长按微信首页右上角 **＋** 打开功能菜单：顶部显示当前版本、内核版本与服务器版本，下面分为 **聊天 / 红包 / 防撤回 / 设置与支持** 四类，点一下即可开关。

首次安装所有开关默认关闭，按需开启。

## 安装

1. 手机已 Root，并安装 LSPosed（Zygisk 版）；
2. 安装本仓库 Releases 里的 APK；
3. 在 LSPosed 中启用本模块，作用域选择「微信」；
4. 强制停止微信后重新打开。

## 更新

内核由服务器分发：菜单里「检查内核更新」或首页版本行即可升级，无需重装 APK。更新后重启微信生效。

## 常见问题

**Q：装上后没有看到任何功能？**
A：确认微信为 8.0.80（3220）；确认 LSPosed 中已启用模块并勾选微信作用域；确认微信是强制停止后重新启动的。

**Q：朋友圈防删没有生效？**
A：菜单里该开关需处于开启状态；只对他人动态生效。

**Q：会不会收集聊天内容？**
A：不会上传聊天或朋友圈内容；仅在版本更新检查与真名查询时与服务器通信。

## 已知限制

1. 仅支持微信 8.0.80（3220），8.0.79 及更早版本不支持；
2. 广告类朋友圈动态不保留；
3. 自己删除自己的朋友圈不拦截；
4. 微信大版本升级后需要等待适配。
