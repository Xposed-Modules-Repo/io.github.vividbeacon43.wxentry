# WXEntry · 微信增强模块

面向微信 8.0.80（3220）的 LSPosed 模块。

> 仅支持微信 8.0.80（3220）。
> 需要最新版模块（APK），以及 **LSPosed（Zygisk 版）2.0 及以上**（实测 v2.2.1 正常）。

## 功能

**聊天**

- 防撤回（原消息后标注「已撤回」，撤回的图片、视频、文件仍可查看）
- 自动下载原图（独立开关）
- 原图下载黑白名单（个人 / 群聊）
- 语音防撤回
- 批量转发语音
- 一键已读
- 清空聊天列表
- 新群免打扰
- 公众号取关

**朋友圈**

- 朋友圈防删
- 朋友圈一键转发（高级版 / VIP）

**其它**

- 群聊尾名显示
- 自动勾选原图
- 红包助手（免费版前台自动领取，高级版 / VIP 可选静默）
- 自动接收转账（高级版 / VIP）
- 内核更新
- 重启微信
- 平板模式与平板扫码登录（高级版 / VIP）

## 使用

微信首页点右上角「＋」，在展开的面板里点「微信增强」。

## 安装

1. 已 Root，并安装 LSPosed（Zygisk 版，2.0 及以上）；
2. 安装本仓库 Releases 里的最新版 APK；
3. LSPosed 中启用本模块，作用域选「微信」；
4. 强制停止微信后重新打开。

## 更新

菜单内「检查内核更新」，更新后重启微信生效。
